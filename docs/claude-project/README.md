# docs/claude-project

Context pack for the **Mnemio** project in Claude Desktop (and any other
long-running AI workspace).

| File | Purpose |
|---|---|
| `00-PROJECT-INSTRUCTIONS.md` | The text to paste into the project's custom instructions. |
| `01-mnemio-context.md` | Dated snapshot of the product, stack, architecture, data model, flows, caps, SEO surface, deferred work and known-stale docs. **The one file to keep refreshed.** |
| `02-notion-knowledge-base.md` | Structure and working rules for Mnemio's Notion KB, plus bootstrap prompts. |
| `03-what-to-upload.md` | Which files to upload / connect / never upload, the refresh ritual, and a first-session checklist. |

Refresh `01` after any sprint that changes architecture, the API, pricing or the
stack — the exact prompt is at the end of `03-what-to-upload.md`.
